## Caso 1: Restaurante Mexicano "Los Cuates"

- **Ubicación**: Centro comercial en Cuernavaca, México
- **Capacidad**: 80 personas
- **Pantalla LED**: 55" en entrada principal
- **Problema**: Menú impreso desactualizado, costos de impresión altos

```json

  "menuItems": [
    {
      "name": "Flautas",
      "description": "Tortilla crujiente rellena de pollo",
      "price": "$85.00",
      "image": "flautas.jpg"
    },
    {
      "name": "Huarache de Cecina",
      "description": "Masa artesanal con cecina de Yecapixtla",
      "price": "$120.00",
      "image": "huarache.jpg"
    }
  ]
}
```

### Proceso de Creación
1. **Día 1**: Subir fotos de platillos reales (smartphone)
2. **Día 1**: Aplicar "Copywriting Epic" para mejorar descripciones
3. **Día 1**: Seleccionar modo "GALA" para ambiente premium
4. **Día 2**: Exportar MP4 y transferir a USB
5. **Día 2**: Configurar loop en pantalla LED

### Resultados
- ✅ Tiempo de implementación: 2 días (vs 2 semanas con diseñador)
- ✅ Costo: $0 (vs $800 por video profesional)
- ✅ Actualización de precios: 5 minutos (vs reimpresión de menús)
- ✅ Incremento en ventas de platillos destacados: +35%

## Caso 5: Pizzería con Promociones Rotativas

### Contexto del Negocio
- **Ubicación**: Delivery + local, Puebla
- **Capacidad**: 30 personas + delivery
- **Pantalla LED**: 50" en área de espera
- **Problema**: Promociones cambian cada semana

### Configuración Dinámica
```json
{
  "restaurantName": "Pizza Express",
  "accentColor": "#DC143C",
  "sceneDuration": 90,
  "menuItems": [
    {
      "name": "Pizza Hawaiana",
      "description": "Jamón, piña, queso mozzarella",
      "price": "$149.00",
      "image": "hawaiana.jpg"
    },
    {
      "name": "PROMO: 2x1 Martes",
      "description": "Compra 1 pizza grande, lleva 2",
      "price": "$249.00",
      "image": "promo-2x1.jpg"
    }
  ]
}
```

### Flujo de Trabajo Semanal
**Lunes**: Planear promoción de la semana  
**Martes**: Editar menú (añadir slide de promo)  
**Martes 12pm**: Exportar nuevo MP4  
**Martes 1pm**: Actualizar pantalla  
**Domingo**: Remover promo, volver a menú base

### Herramientas Utilizadas
- **Modo FEST**: Para promociones (color rojo vibrante)
- **Modo GALA**: Para menú regular (dorado elegante)
- **Copywriting Epic**: Para textos de urgencia ("¡Solo hoy!")

### Resultados
- ✅ Ventas en días de promo: +60%
- ✅ Tiempo de actualización: 10 minutos
- ✅ Flexibilidad: Cambiar promo en tiempo real si no funciona
- ✅ Engagement: Clientes preguntan por "la promo de la pantalla"
