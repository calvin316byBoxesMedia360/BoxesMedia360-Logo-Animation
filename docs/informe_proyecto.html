DESCRIPCION_GENERAL_Y_PROPOSITO

¿QUÉ ES Y PARA QUÉ FUE CREADO?

VIDEOSTUDIO_OS (Digital Menu Studio) es una plataforma de señalización digital programática concebida para automatizar el diseño y la renderización de menús dinámicos para restaurantes y entornos de venta. Fue creado para responder a la necesidad de actualizar precios, platillos y promociones de forma instantánea desde una base de datos centralizada y compilar dichos cambios automáticamente en videos fluidos MP4 en alta definición, evitando el laborioso proceso de re-edición de video manual.

Las composiciones y transiciones cinemáticas (como el zoom progresivo Ken Burns) se describen mediante código React y componentes web estándar, lo que garantiza una fluidez constante de 30fps sin pérdida de fidelidad en la previsualización del navegador y en la exportación del renderizador Remotion.

APLICACION_PRACTICA

  • [✓] Cartelería en Restaurantes: Menús dinámicos proyectados en Smart TVs de forma física vertical u horizontal en el local comercial.
  • [✓] Renders Locales Rápidos: Compilación directa a video MP4 optimizada en el equipo local del administrador del sistema.
  • [✓] Flexibilidad Física: Soporte de rotación a -90° (girado a la izquierda) en canvas de 1920x1080 para pantallas físicamente montadas verticales en la pared.

FUNCIONALIDADES_CLAVE

  • · Smart Blurred Fit: Doble capa de imagen para que los logos/productos no se corten, recortando 5px/2px exteriores con clipPath para eliminar los halos blancos de los bordes.
  • · Local Browser Bypass: Detección de Chrome/Edge en el host local de Windows para usar códecs H.264 nativos del sistema.
  • · Panel de Control Completo: Ajustes de insets, overlays, animaciones y paddings directamente en el dashboard.

TECNOLOGIAS_Y_HERRAMIENTAS

FRONTEND_STUDIO

Vite v7.3.1 React v19.2.3 TailwindCSS v4.0.0 Lucide Icons

La interfaz gráfica de usuario está empaquetada con la última versión de Vite y ofrece controles interactivos glassmorphic dinámicos montados en React.

VIDEO_ENGINE

Remotion v4.0.419 Remotion Player Remotion Bundler Puppeteer

El renderizado de videos programáticos utiliza Remotion, el cual genera composiciones en HTML/React y las captura frame por frame mediante Chromium headless para renderizar el video a H.264.

BACKEND_SERVICES

Express v5.2.1 Firebase Admin SDK CORS Middleware

Un servidor local en Express gestiona las peticiones de renderizado e implementa un proxy para reenviar contenidos salteando bloqueos de CORS, además de integrarse con Firebase Storage/Firestore.

REGISTRO_DE_ERRORES_Y_RESOLUCIONES

ERROR_DETECTADO CAUSA_RAIZ RESOLUCION_IMPLEMENTADA
CORS Error (Image load failure) Firebase Storage no envía las cabeceras Access-Control-Allow-Origin al navegador. Desarrollado un endpoint proxy `/api/proxy?url=...` en Express que descarga el recurso y lo transmite con cabeceras de origen abierto.
Fringe line (White line) on scene transition Bordes de subpíxeles o ruido de transparencias en los PNGs/JPGs cargados por el usuario. Aplicación de la propiedad CSS `clipPath: 'inset(5px 2px)'` en el renderizado frontal del platillo para recortar bordes ruidosos.
PIPELINE_ERROR_DECODE (Failed to send video packet) El Chromium headless por defecto no tiene licencias integradas para reproducir códecs comerciales H.264/AAC. Script de render modificado para escanear y forzar el uso del binario de Google Chrome o Microsoft Edge local del sistema en Windows.

LISTA_COMANDOS_SISTEMA

1. INICIAR_SERVICIOS_DESARROLLO

Ejecuta el servidor de base de datos e interfaz local de forma independiente:

# Terminal A :: Inicia el Servidor Express (Local API / Proxy / Render)
npm run server

# Terminal B :: Inicia el Dashboard del Panel de Control de Vite
npm run dashboard

2. PROBAR_COMPILACION_Y_EMPAQUETADO

Realiza las pruebas de transpilación y construcción de artefactos antes de enviar a producción:

# Comprobar la compilación y empaquetar el dashboard de Vite
npm run build:dashboard

# Compilar y empaquetar el bundle estático de Remotion
npm run build

3. PRUEBA_RENDER_DIRECTO_DESDE_CLI

Dispara el renderizado de forma directa por línea de comandos utilizando una configuración local:

# Renderizar usando un archivo menu-config.json
node scripts/render-video.js
